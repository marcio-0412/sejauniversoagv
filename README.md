# AGV Network Builder

PROJECT GOAL

Create a premium, high-conversion recruitment landing page for a Brazilian vehicle protection association called "Universo AGV".

The goal of the page is to recruit new consultants, sales professionals, and insurance brokers to join the commercial network.

The design must be INSPIRED BY APPLE'S VISUAL STYLE:
minimalist, elegant, modern, clean, and premium.

The page must communicate:

• Authority
• Credibility
• Market opportunity
• Professional structure
• Growth potential

The landing page must feel like a large, structured national organization.

--------------------------------------------

DESIGN STYLE (VERY IMPORTANT)

Use a visual style inspired by Apple:

• Minimalist layout
• Large typography
• Lots of white space
• Smooth section transitions
• Clean modern icons
• Elegant spacing
• Subtle animations
• Premium UI components

Avoid clutter and visual noise.

Everything should feel modern and premium.

--------------------------------------------

COLOR PALETTE

Primary color:
Deep institutional blue

Secondary colors:
White
Light gray
Black for titles

Buttons:
Primary CTA → Blue
Secondary CTA → Outline style

--------------------------------------------

TYPOGRAPHY

Use a modern professional font such as:

Inter
SF Pro
or similar Apple-style font

Headlines must be large and impactful.

Body text must be easy to read.

PAGE STRUCTURE

Follow the exact structure below.

--------------------------------------------

SECTION 1 — HERO (FIRST FOLD)

Full-screen section.

Minimalist background (soft gradient or light abstract pattern).

"Uma das maiores associações de proteção veicular do Brasil está expandindo sua rede de consultores."

"Trabalhe com o Universo AGV e faça parte de uma operação que já protegeu mais de 1 milhão de veículos em todo o país."

"Estamos buscando consultores comerciais, corretores de seguros e profissionais de vendas que desejam atuar em um mercado em constante crescimento."

Secondary:
"Falar com um gestor no WhatsApp"

Include subtle scroll indicator.
